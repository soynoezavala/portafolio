NOÉ ZAVALA — MEDIA KIT

CÓMO ABRIRLO CON XAMPP
1. Descomprime la carpeta.
2. Copia "noe-zavala-media-kit-final" a C:\xampp\htdocs\
3. Inicia Apache en XAMPP.
4. Abre http://localhost/noe-zavala-media-kit-final/

PARA EDITAR "SOBRE MÍ"
Abre index.html y busca: EDITA AQUÍ TU TEXTO SOBRE MÍ

PARA AGREGAR REDES
Abre index.html y busca la sección id="contacto". Sustituye los href="#".

Los videos de Drive requieren permiso: "Cualquier persona con el enlace puede ver".
