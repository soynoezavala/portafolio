# Noé Zavala — Portafolio v1.0

Sitio estático listo para XAMPP y GitHub Pages.

## Abrir en XAMPP

1. Copia la carpeta `noe-zavala-web` dentro de `xampp/htdocs/`.
2. Enciende Apache.
3. Abre `http://localhost/noe-zavala-web/`.

## Incluye

- Hero editorial y secciones claras/oscuras.
- Narración destacada con Google Drive.
- Proyecto Blue Lock con YouTube.
- Episodio de Spotify embebido.
- Estadísticas, incluyendo 16K+ en TikTok.
- Ocho portadas hechas exclusivamente con las imágenes reales entregadas por Noé; solo fueron recortadas, ajustadas y optimizadas a WebP.
- Tarjetas que abren los videos originales de TikTok en una pestaña nueva.
- Botón **Ver más** hacia el archivo de transmisiones en vivo de Vendedores de Humo en YouTube.
- Iconos SVG reales para Instagram, TikTok, YouTube, Facebook, Spotify y correo.
- Footer con fotografía de estadio, frase e iconos sociales.
- Responsive y animaciones sutiles.

## Datos por confirmar

Busca en `index.html` y reemplaza estos valores cuando tengas los enlaces definitivos:

- `https://www.youtube.com/@VendedoresdeHumo/streams` — confirma el handle exacto del canal.
- `href="#"` de Instagram.
- `href="#"` de Facebook de Vendedores de Humo.
- `correo@ejemplo.com`.

## Publicar en GitHub Pages

Sube el contenido de esta carpeta a un repositorio y activa GitHub Pages desde **Settings → Pages** usando la rama principal y la carpeta raíz.
